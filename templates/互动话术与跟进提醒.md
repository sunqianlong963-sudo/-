# 互动话术 & 跟进提醒模板（全中文）

> 这是获客转化的"嘴替"：评论怎么回、私信怎么聊、隔几天怎么跟进，都给你写好话术。
> 配合 `scripts/跟进提醒生成器.py` 使用——脚本告诉你"今天该跟进谁"，这里给你"该说什么"。

---

## 一、评论区互动话术

**目标：把公开评论引导到私信/私域，同时不显得生硬。**

| 场景 | 话术示例 |
|---|---|
| 有人扣关键词领资料 | 「已私信你啦，注意查收～有问题随时问我😊」 |
| 有人问"怎么做" | 「这个问题挺重要的，我私信你说更清楚～」 |
| 有人质疑/抬杠 | 「理解你的顾虑～每个人情况不同，我说的只是我的经验，供参考🙏」 |
| 单纯夸赞 | 「谢谢你的支持！这对我太重要啦，会继续更新的❤️」 |
| 同行/想合作 | 「感谢关注～合作的话可以私信我详聊～」 |

---

## 二、私信首次回复话术（第一印象很关键）

**不要一上来就推销，先建立信任、了解需求。**

```
你好呀～看到你对【主题/资料】感兴趣😊
先发你刚说的【资料/链接】👉【内容】

顺便了解一下，你现在主要是想解决【XX 问题】对吗？
我可以根据你的情况给点具体建议～
```

> 要点：① 先给价值（兑现承诺的资料）② 再问一个开放问题，把对话延续下去。

---

## 三、需求确认 & 软转化话术

当对方回复了需求后：

```
明白啦～你这个情况其实挺常见的，核心是【一句话点出问题本质】。

我之前帮过不少类似的【人群】，一般是这么做的：
1. ……
2. ……

如果你想更系统地解决，我这边有【产品/服务/课程】，
可以先看下是否适合你，不合适也没关系，资料你先用着😊
```

## 四、跟进话术（按"距上次联系天数"分级）

> `跟进提醒生成器.py` 会根据线索状态和最后联系日期，自动提醒你用下面哪一档话术。

### 📌 第 1 次跟进（联系后 2-3 天没回复）
```
在吗～上次发你的【资料】看了吗？
有什么不清楚的地方都可以问我，不急哈😊
```

### 📌 第 2 次跟进（约 1 周后）
```
Hi～最近在忙吗？
我这边刚整理了一个【新的干货/案例】，感觉对你之前说的【需求】挺有用，
要不要发你看看？
```

### 📌 第 3 次跟进（约 2 周后，给台阶）
```
好久没联系啦～如果暂时还没需要也完全 ok，
我先不打扰你了，需要的时候随时来找我就行～
有需要我第一时间帮你😊
```

> 跟进原则：**给价值 > 催成交**。每次跟进都带一点新东西（资料/案例/优惠），
> 而不是单纯问"考虑得怎么样了"。第 3 次还没回应就转入"长期培育"，不再频繁打扰。

## 五、成交后 & 转介绍话术

```
谢谢你的信任！🎉 后续使用有任何问题随时找我。

对了，如果身边有朋友也需要【XX】，欢迎帮我介绍～
老客户介绍可以享【专属福利】，也算我谢谢你的支持😊
```

---

## 六、提醒文案风格约定

脚本生成的所有提醒、给你的待办清单，都遵循以下风格：

- ✅ 全中文、口语化、带少量 emoji，方便快速扫读
- ✅ 每条提醒包含：**联系谁 + 距上次几天 + 用第几档话术 + 一句话需求摘要**
- ✅ 按紧急度排序（拖得越久越靠前）
