# 飞书群接入指南（半小时搞定）

目标：建一个"XX公司总部"飞书群，你 + 所有AI员工都在里面。员工干完活自动发消息进群，你在手机上看汇报、发指令。

## 第一步：建群 + 加机器人（手机上5分钟）

1. 飞书 → 创建群聊，命名比如「乾龙AI公司总部」
2. 群设置 → 群机器人 → 添加机器人 → 自定义机器人
3. 机器人命名「大聪明」，头像随便选一个
4. 创建后会得到一个 Webhook 地址（https://open.feishu.cn/open-apis/bot/v2/hook/xxxx），复制保存好——这是大聪明往群里发消息的"嘴"
5. （可选）安全设置选"自定义关键词"，填「日报」或公司名，防止别人乱用

以后每加一个AI员工，就重复第2-4步再加一个自定义机器人（选题员、文案员各一个），这样群里能看出是谁在发言。

## 第二步：装"发言脚本"（电脑上）

在大聪明的项目文件夹里建 scripts/发飞书.sh（内容见同目录文件），把里面的 WEBHOOK 换成你第一步拿到的地址。

测试：终端里运行

```
bash scripts/发飞书.sh "大聪明已上线，向董事长报到 ✅"
```

手机飞书群里收到消息，即接通。

## 第三步：让大聪明学会用它

CLAUDE.md 里已写了汇报制度，再补一句话到文件末尾即可：

发飞书群的方式：运行 bash scripts/发飞书.sh "消息内容"。日报生成后必须发一份到群里。

然后打开 Claude Code，对大聪明说一句「生成今天的日报并发到飞书群」，验证全链路。

## 第四步（以后）：定时上班

跑顺之后，把这条挂到系统定时任务（macOS 用 launchd / crontab），每天早上7点自动执行：

```
cd ~/大聪明公司 && claude -p "读取所有员工最新产出，生成董事长日报并发飞书群" --dangerously-skip-permissions
```

## 常见坑

- Webhook 地址等于群的钥匙，别发到公开地方
- 自定义机器人只能"发"不能"读"群消息。你在群里@它它是看不到的——现阶段你给大聪明下指令还是在 Claude Code 里说，或写到 待办/ 文件夹。想让它能读群消息，后面再升级成飞书开放平台的企业自建应用（免费，但配置多半小时），跑顺了再搞
- 消息发不出去，九成是安全设置的关键词没匹配上，把关键词删掉或在消息里带上关键词
