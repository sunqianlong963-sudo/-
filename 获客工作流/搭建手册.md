## 3. 5 周落地路线图

### 🟢 第 1 周：内容生产模块

**目标**：每天 9 条内容自动产出（3 选题 × 3 平台）

**步骤**：
1. 注册扣子 Coze 账号 → https://www.coze.cn
2. 在 Coze 中创建一个机器人 + 一个工作流
3. 在飞书新建多维表格 → 导入 `01_选题库.csv`
4. 按 `03_Coze工作流设计.md` 搭建工作流节点
5. 把 3 个 Prompt 模板分别配置到 3 个 LLM 节点
6. 测试：手动跑一次，检查产出的 3 篇稿子质量
7. 配置定时触发：每天 9:00 / 14:00 / 20:00 各跑一次

**验收标准**：每天能自动产出 9 篇可用稿件，人工微调时间 ≤ 30 分钟/篇。

---

### 🟢 第 2 周：多平台一键发布

**目标**：1 份内容同步发布到 6+ 平台

**步骤**：
1. 注册「蚁小二」或「易媒助手」（推荐蚁小二，UI 更友好）
2. 在工具内绑定运营人员的所有平台账号（注意：用工具方的扩展插件登录，不要直接给账号密码）
3. 设置发布模板：抖音/视频号用同一份口播稿；小红书图文单独；知乎/公众号单独
4. 配置定时发布：抖音 19:00-21:00；小红书 12:00 和 21:00；知乎 19:30；公众号每周二/五 18:00
5. 培训运营：从 Coze 产出 → 微调 30 分钟 → 蚁小二一键发布

**合规提醒**：
- ⚠️ 同一份口播稿在不同平台请改头去尾，避免被判搬运
- ⚠️ 不同账号矩阵之间内容必须有差异化，否则限流
- ⚠️ 视频不要用 AI 一键搬运，至少做剪辑/配音差异化

---

### 🟢 第 3 周：飞书 CRM 线索表

**目标**：所有渠道线索统一沉淀，看板可视化

**步骤**：
1. 飞书新建多维表格 → 命名「线索池」
2. 导入 `04_飞书CRM线索表.csv` 作为表头
3. 配置 4 个视图：
   - 「新线索（24h 内）」：按"首次互动时间"倒序，意向等级=A 红色高亮
   - 「我的跟进」：按"负责销售"=当前用户 筛选
   - 「今日跟进」：下次跟进时间=今天
   - 「已成交」：跟进状态=已成交，看转化漏斗
4. 配置自动化规则：
   - 新增线索 → 按客群自动分配销售（用「自动化流程」插件）
   - 跟进状态变更 → 飞书消息提醒销售
   - A 级线索 24h 未跟进 → 推送给主管

**验收标准**：销售只用飞书 App 就能完成所有跟进动作，主管在仪表盘看转化漏斗。

---

### 🟡 第 4 周：评论监听 + 引流话术库

**目标**：自动识别"试听""咨询""价格"等关键词，引导到私域

**两种方案**：

**方案 A（推荐）：人工监听 + 话术库**（合规、零成本）
1. 飞书多维表格新建「话术库」表
2. 按关键词分类：试听类 / 价格类 / 异议类 / 引流类
3. 每个关键词配 3-5 条话术变体（防止平台判定为机器人）
4. 运营每天 2 次集中处理评论，从话术库快速复制

**方案 B：飞鱼 CRM / 媒小三 监听**（付费、半自动）
1. 在飞鱼绑定抖音/小红书账号
2. 设置关键词监听：试听/价格/课程/咨询
3. 触发后自动推送到飞书群+生成线索

**⚠️ 私信自动回复的红线**：
- 小红书：私信前 3 条人工发，不要批量化
- 抖音：同一话术 24h 内不要发超过 30 条
- 引导加微信：用"主页有暗号"代替"加微信"，用谐音"V""薇"会被限流

---

### 🟡 第 5 周：企微 SOP 自动跟进

**目标**：用户加企微后自动触发 7 天孵化流程

**步骤**：
1. 注册企业微信 + 申请「客户联系」权限
2. 注册微伴助手 / EC SCRM（推荐微伴，性价比高）
3. 配置「欢迎语 SOP」：
   - Day 0：欢迎语 + 试听课链接
   - Day 1：发一篇行业干货（从 Coze 知乎稿改编）
   - Day 3：发一段学员案例视频
   - Day 5：发限时优惠
   - Day 7：1V1 邀约
4. 配置「标签自动化」：用户回复"试听"自动打标"高意向"，推送给销售

## 4. 团队分工建议（2-5 人小团队）

| 角色 | 人数 | 日常工作 | 工具 |
|------|------|---------|------|
| 操盘手（你） | 1 | 制定选题方向、Review 内容、看数据 | 飞书、蝉妈妈 |
| 内容编辑 | 1 | Coze 产出后微调、剪辑、配图 | Coze、剪映、Canva |
| 平台运营 | 1 | 发布、评论、私信、维护账号 | 蚁小二、各平台 App |
| 销售 | 1-2 | 跟进线索、试听课转化、复购 | 飞书 CRM、企微 |

**关键原则**：每个人只用 2 个工具，复杂工作流由操盘手统一搭建。

## 5. 合规红线（必读）

| ❌ 高风险动作 | ✅ 合规替代 |
|--------------|------------|
| 用脚本批量私信 | 关键词触发 + 人工 30 秒内回复 |
| 一份视频 N 个账号搬运 | 同选题不同口播+不同剪辑 |
| 在评论里直接发"加微信XXX" | 引导到主页/置顶/暗号 |
| 用未授权工具登录别人账号 | 用平台官方授权或扩展登录 |
| 承诺"100% 学会""包过" | 改为"系统训练""科学方法" |
| 用学员真名做案例 | 化名 + 学员书面授权 |
| 直接复制爆款笔记 | 框架可借鉴，案例必须原创 |

## 6. 常见问题（FAQ）

**Q1：Coze 调用 LLM 要付费吗？**
A：Coze 自带的豆包模型免费额度够小团队用 1-2 个月。超出后充值豆包/通义 API Key，约 0.001-0.01 元/千 token，每篇稿子成本 0.05-0.2 元。

**Q2：抖音/小红书账号会被封吗？**
A：纯人工+合规操作不会。**风险点是：① 用自动化工具批量私信 ② 多账号矩阵内容雷同 ③ 评论引流话术过于露骨**。按本手册第 5 节走基本安全。

**Q3：为什么不用 GPT-4？**
A：① 中文表达豆包/通义更贴本土语境 ② 网络稳定性更好 ③ 价格更便宜。Claude 适合用来跑知乎长文，因为中长文逻辑性更强。

**Q4：小红书禁止"加V""加微信"，怎么引流？**
A：在简介/置顶笔记里放"暗号"，例如「主页置顶笔记『职场表达 21 天』评论扣 666 解锁完整训练手册」。把承接动作藏在内容里。

**Q5：我现在 0 粉丝，工作流跑起来有用吗？**
A：内容生产模块立刻有用——能让你 1 周内积累足够素材开始铺量。但**起号期最重要的不是工具，是你的人设和首批 10 条爆款**。建议第 1 周先把工作流跑通，第 2-4 周亲自下场打磨爆款，第 5 周起团队接管常规运营。

**Q6：能不能完全无人值守？**
A：⚠️ **不建议**。原因有两个：①平台对完全无人值守的账号会降权；②演讲口才属于高客单价非标服务，客户决策需要"人"的温度。本手册的定位是「**70% 自动化 + 30% 人工**」——让你少做重复劳动，专注高价值动作。
