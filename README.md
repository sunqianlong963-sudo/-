# 社媒获客自动化系统

面向**小红书 / 抖音·视频号 / 微信（公众号·视频号）**的内容获客自动化方案。
目标：用最少的人力，持续产出内容、沉淀线索、自动跟进，把"获客"变成一条可重复的流水线。

> ⚠️ **重要合规说明**
> 小红书、抖音、微信均**不提供**面向个人/商家的开放"自动发布"接口。
> 任何"自动登录 + 自动发帖 + 自动评论"的工具都违反平台规则，极易限流封号。
> 因此本系统**不做自动发帖**，只把"能合规自动化的部分"做到极致：
> 内容批量生产、排期管理、线索沉淀、自动跟进提醒、数据复盘。
> 发布动作保持"脚本备好内容包 → 你一键手动发"。

---

## 整体架构（获客流水线）

```
①内容生产 ──→ ②排期&发布清单 ──→ ③人工发布 ──→ ④线索沉淀&跟进 ──→ ⑤数据复盘
  (全自动)        (全自动)          (半自动)        (全自动)         (全自动)
   Claude         脚本+Drive        人工           脚本+Gmail      Supermetrics
   +Canva
```

| 环节 | 自动化程度 | 工具 | 对应文件 |
|---|---|---|---|
| ① 内容批量生产 | 🟢 全自动 | Claude + Canva | `templates/` 下各平台模板 |
| ② 内容排期 / 发布清单 | 🟢 全自动 | Python 脚本 + Google Drive | `scripts/内容排期生成器.py` |
| ③ 发布动作 | 🟡 半自动 | 人工（脚本备好内容包） | `docs/落地方案.md` |
| ④ 线索沉淀 + 跟进提醒 | 🟢 全自动 | Python 脚本 + Gmail | `scripts/跟进提醒生成器.py` |
| ⑤ 数据复盘 | 🟢 全自动 | Supermetrics | `docs/落地方案.md` |

## 快速开始

1. 读 `docs/落地方案.md`，了解整条流水线怎么跑。
2. 用 `templates/` 里的模板 + Claude/Canva 批量生产第一批内容。
3. 把收集到的线索填进 `线索管理/线索表模板.csv`。
4. 运行 `scripts/跟进提醒生成器.py`，得到当天该跟进谁、用什么话术。

> 你不懂代码也没关系：每个脚本都自带示例数据，可以让 Claude 帮你跑，
> 或用 GitHub Actions 设成每天定时自动跑（见 `docs/落地方案.md` 最后一节）。
