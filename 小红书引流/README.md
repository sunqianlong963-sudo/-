# 小红书引流内容包 · 演讲口才培训

> 目标:替换"故事型内容"打法,改为「痛点方法型 + 场景模板型 + 自测互动型」三类内容,
> 一周内完成 A/B 测试,找出能跑量的选题方向,把流量导入私域(免费 1v1 口才测评钩子)。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `选题标题库20条.md` | 20 个选题,含标题 + 封面大字 + 切入角度,按三类分组 |
| `爆款结构与封面规范.md` | 笔记五段式结构、封面标题三原则、引流话术规范 |
| `成稿示例3篇.md` | 三类内容各 1 篇完整成稿,可直接替换细节后发布 |

## 一周测试节奏(建议)

| 天 | 动作 |
| --- | --- |
| 第 1-2 天 | 发 2 篇痛点方法型(选题库 1、3) |
| 第 3-4 天 | 发 2 篇场景模板型(选题库 9、11,蹭年中述职季) |
| 第 5 天 | 发 1 篇自测互动型(选题库 17,对接六维测评 H5) |
| 第 6-7 天 | 复盘数据:看曝光、点击率(封面问题)、收藏率(内容问题)、私信数(钩子问题) |

**判断标准:**
- 曝光 < 500:选题/关键词没被系统识别,换选题
- 曝光高但点击率 < 5%:封面标题问题,换封面
- 点击高但收藏/互动低:内容结构问题,加干货密度
- 互动高但私信少:钩子埋得不显眼,调整评论区引导
